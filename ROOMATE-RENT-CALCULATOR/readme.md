# Roommate Rent Calculator

## About the Project

The Roommate Rent Calculator is a beginner-friendly Python mini project that calculates the total monthly household expenses and divides them equally among three roommates.

## Features

* Accepts the names of three roommates.
* Takes rent and monthly utility bills as input.
* Calculates total monthly expenses.
* Divides the expenses equally among three roommates.
* Displays the payment amount for each roommate.

## Technologies Used

* Python 3

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   `python rent_calculator.py`

## Expense Formula

Total Expense = Rent + Electricity + Water + Wi-Fi + Other Expenses

Each Roommate's Share = Total Expense / 3
