# 🏠 Roommate Rent Calculator

A beginner-friendly Python mini project that calculates monthly household expenses and splits the total equally among three roommates.

## 📌 About the Project

Sharing a flat with roommates means sharing rent, electricity, water, Wi-Fi, and other household expenses. Calculating everyone's contribution manually can be inconvenient.

The **Roommate Rent Calculator** simplifies this process by taking monthly expenses as input, calculating the total cost, and determining how much each of the three roommates needs to pay.

## ✨ Features

* 👥 Accepts the names of three roommates.
* 🏠 Takes monthly house rent as input.
* ⚡ Includes electricity and Food bills.
* 📶 Includes other expenses.
* 🧮 Calculates total monthly expenses automatically.
* 💰 Divides expenses equally among three roommates.
* 📊 Displays a clear monthly expense report.

## 🛠️ Technologies Used

## 🧮 How It Works

The program asks the user to enter the names of three roommates and the monthly household expenses.

### Calculation Formula

**Total Monthly Expense**

Total Expense = Rent + Electricity + Water + Wi-Fi + Other Expenses

**Individual Contribution**

Each Roommate's Share = Total Expense ÷ 3

The program then displays the total expense and the amount payable by each roommate.
